## 💬 FAQ

**Q: Which document should I read first?**  
A: [FREE_DEPLOYMENT_RAILWAY.md](FREE_DEPLOYMENT_RAILWAY.md) if you want to deploy now. [FREE_DEPLOYMENT_SUMMARY.md](FREE_DEPLOYMENT_SUMMARY.md) if you want to understand options first.

**Q: Can I really deploy for free?**  
A: Yes! Railway gives $5/month free credit. Spring Boot + Python + PostgreSQL fit within this.

**Q: Do I need Docker?**  
A: Nope! Railway auto-detects and builds from source (pom.xml, requirements.txt).

**Q: What if I need more resources?**  
A: Easy to upgrade in Railway dashboard. Scales vertically first, then horizontally.

**Q: Can I rollback if something goes wrong?**  
A: Yes! Railway keeps deployment history. Click previous version to rollback.

**Q: Is Railway stable for production?**  
A: Yes! Uses AWS infrastructure, 99.9% SLA, auto-restarts, SSL included.
